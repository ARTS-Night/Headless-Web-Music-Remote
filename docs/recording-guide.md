# README demo capture guide

When a short visual is available, add it under `docs/media/` and link it from the README's introduction. Do not add a README image link before the asset exists.

Record a 10–20 second GIF or video showing:

1. `hwmr.exe` starting on Windows and printing the phone URL and pairing code.
2. A phone opening the trusted-LAN URL and pairing.
3. The YouTube viewer receiving a frame.
4. Phone scroll and tap controls changing the remote page.
5. PC audio continuing while the Windows foreground window and mouse remain untouched.

Hide pairing codes, tokens, account information, browser history, and private notifications before recording.
